# ALS Analytics Intelligence Corp.

Daily decision briefings for local government leaders.

## Deploy with GitHub Pages

1. Go to **Settings** → **Pages**
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**
3. Branch: **main** / **/(root)**
4. Click **Save**

Your site will be live at:
**https://athenapenelopemarie.github.io/als-analytics/**
